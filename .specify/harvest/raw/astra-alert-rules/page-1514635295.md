# Azure Bot integration with MS Teams

**Overview**

This document describes the steps required to integrate an application with Microsoft Teams using Azure Bot Service.

**The integration includes:**

- **Azure App Registration**
- **Azure Bot Service creation**
- **Microsoft Teams channel configuration**
- **Messaging endpoint configuration**
- **Teams App manifest creation (via Developer Portal)**

**Prerequisites**

- **Azure Subscription**
- **Azure AD access**
- **Public HTTPS endpoint **
- **Access to Microsoft Teams Admin Center**
- **Developer Portal for Microsoft Teams access**

**Step 1: Create Azure App Registration**

- **Navigate to Azure Portal**
- **Go to Azure Active Directory**
- **Select App registrations**
- **Click New registration**

**Provide:**

**Name: **e.g., observex-teams-bot

**Supported account types:**
Single tenant or Multi-tenant

**Click Register**

**Save:**

- **Application (Client) ID**
- **Directory (Tenant) ID**

**Step 1.1: Create Client Secret**

- **Go to Certificates & Secrets**
- **Click New client secret**
- **Add description & expiry**
- **Click Add**
- **Copy the secret value immediately**

**This will be used as:**

**MicrosoftAppId = Application (Client) ID**
**MicrosoftAppPassword = Client Secret**
**MicrosoftAppTenantId = Directory (Tenant) ID**

**Step 2: Create Azure Bot Resource**

- **Go to Azure Portal**
- **Search for Azure Bot**
- **Click Create**

**Fill:**

**Bot Handle**

**Subscription**

**Resource Group**

**Region**

**Microsoft App ID → Select existing app registration**

- **Click Review + Create**
- **Click Create**

**Step 3: Configure Messaging Endpoint**

- **Open the Azure Bot resource**
- **Go to Configuration**
- **Set the Messaging Endpoint:**

**<https://<your-public-domain>>/api/messages**

**Click Apply**

**Step 4: Enable Microsoft Teams Channel**

- **Open Azure Bot**
- **Go to Channels**
- **Select Microsoft Teams**
- **Click Save**

T_his connects the bot to Teams._

**Step 5: Create Teams App Manifest (Developer Portal)**

**This step is required to install the bot inside Microsoft Teams.**

**5.1 Open Developer Portal**

- Open Microsoft Teams
- Search for Developer Portal
- Open the app

OR

Visit:
[https://dev.teams.microsoft.com](https://dev.teams.microsoft.com)

**5.2 Create New Teams App**

- **Click Apps**
- **Click + New App**

_Provide:_

_App Name, Description, Developer details_

**5.3 Configure App ID**

**Under Basic Information:**

**Use the same Application (Client) ID from Azure App Registration**

**This is important — App ID must match the Azure Bot App ID.**

**5.4 Configure Bot**

- **Go to App Features → Bot**
- **Click Set up**

**Enter:**

**Bot ID → Same as Azure App Registration Client ID**

**Select supported scopes:**

**Personal**

**Team**

**Group Chat (if required)**

**Permissions:**

1. **ChannelMessage.Read.Group **
2. **ChatMessage.Read.Chat**

**Enable:**

**Send notifications**

**Click Save**

**5.5 Generate and Download manifest.json**

- **Go to Publish**
- **Click Download app package**

This will download a **.zip file **containing:

**manifest.json**

**color.png**

**outline.png**

**Step 6: Upload/Submit the App to Teams**

- **Submit the app via Teams Admin Center**

**Step 7: Application Configuration**

**In backend application use these values :**

**MicrosoftAppId=<Client ID>**
**MicrosoftAppPassword=<Client Secret>**
**MicrosoftAppTenantId=<Tenant ID>**
